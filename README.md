# 3D 二阶魔方 · 中小学友好教学版

用 **Godot 4.7** 制作的 3D 二阶魔方（口袋魔方）。界面明亮、字号大、按钮大，
并且有“🐻 教练”一步一步地教，特别适合中小学生第一次接触魔方：
可以自己转、可以让电脑带你走一小步、可以看电脑演示，也可以打乱后计时挑战。

---

## 一、运行方法

1. 用 Godot 4.7（或更高版本）打开本文件夹（选中 `project.godot`）。
2. 按 `F5` 运行，主场景是 `scenes/main.tscn`。

命令行方式：

```bash
# 运行游戏
godot --path .

# 无界面逻辑自测（数据表 + 求解器，约 5 秒）
godot --headless --path . --script res://tests/test_logic.gd

# 集成自测（加载真实场景，模拟打乱 / 提示 / 自动复原 / 切换课程）
godot --headless --path . res://tests/integration.tscn

# 面向小朋友的交互自测（下一步提示 / 走一步 / 步骤进度 / 庆祝 / 成绩存档 / 音效）
godot --headless --path . res://tests/kids_ui.tscn

# 求解器压力测试（400 个随机局面）
godot --headless --path . --script res://tests/stress.gd

# 画面自检（真实渲染一帧，检查贴纸颜色与 UI 是否正常绘制）
godot --path . res://tests/visual_check.tscn
```

## 二、操作方式

| 操作 | 效果 |
| --- | --- |
| 按住魔方表面拖动 | 转动对应的那一层（拖动方向 = 该面的移动方向） |
| 空白处拖动 / 右键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| `U` `D` `L` `R` `F` `B` | 转动对应面（`Shift` + 字母 = 反向） |
| `空格` | 打乱 |
| `Z` | 撤销 |
| `H` | 教练提示（分析当前阶段 + 推荐公式） |
| `S` | 自动复原 |
| `V` | 恢复默认视角 |
| `T` / `Esc` | 收起 / 展开教学面板 |

手机 / 触屏：直接拖动即可（鼠标事件由触摸模拟，默认开启）。

### 给小朋友的三个按钮

- **💡 提示**：分析当前局面，在蓝色提示条里用大白话告诉你“下一步该转哪一面、往哪边转”。
- **▶ 走一步**：电脑带你转一小步（不计入你的步数），可以放心跟着学；
  它会沿着一条已经验证过的完整解法一步步走，不会来回打转。
- **🎬 帮我做完这一步**：把当前这一阶段自动做完。

复原成功时会有 **🎉 撒花庆祝** 和一声小小的成功音乐；顶栏可以随时 **🔊 / 🔇** 静音。

## 三、教学系统

左侧面板是 7 节课程，每节课都会自动把魔方摆成适合讲解的局面：

| 课程 | 内容 |
| --- | --- |
| 第 1 课 | 认识二阶魔方与操作方式 |
| 第 2 课 | 公式记号（R / U / F、`'`、`2`）与热身公式 `R U R' U'` |
| 第 3 课 | **第一步**：复原白色一层 |
| 第 4 课 | **第二步**：顶层黄色面（OLL 朝向，6 个标准公式） |
| 第 5 课 | **第三步**：顶层角块归位（PLL，相邻 / 对角互换） |
| 第 6 课 | 完整复原演示（三个阶段串起来） |
| 第 7 课 | 计时挑战（会记住你的最好成绩） |

面板里还有 **三步进度条**（① 白面 → ② 黄面 → ③ 归位），当前该做哪一步会高亮，
做好的会打上 ✅，一眼就知道自己走到哪里了。

**教练功能**

程序会自动判断当前处于哪个阶段，并给出教学化的解法：

1. **阶段 1 · 白色一层**：直接查“白色一层精确距离表”，输出**最优**步数序列。
2. **阶段 2 · 顶层朝向（OLL）**：从 6 个标准公式中匹配当前图案（含 AUF 预转），
   告诉你是哪一种、该用哪个公式；如果不匹配则用“公式 + AUF”的广度优先搜索给出
   由标准公式组合成的解法。
3. **阶段 3 · 顶层归位（PLL）**：同上，匹配相邻互换 / 对角互换公式。

左下角的 **展开图** 固定在面板底部，实时显示 6 个面的配色，转视角不会影响它，
而且会随窗口大小自动放大，非常方便对照公式。

## 四、代码结构

```
project.godot            项目配置（Forward+、MSAA 4x、窗口 1280x760）
scenes/main.tscn         主场景（只有一个挂脚本的根节点，其余用代码构建）
scripts/
  cube_model.gd          魔方逻辑模型：8 个角块的状态、24 种旋转、18 种转动表、
                         贴纸颜色、打乱、序列解析（纯逻辑，无渲染）
  cube_solver.gd         求解器：白色一层精确距离表（BFS）、启发式搜索（IDA*）、
                         OLL / PLL 标准公式匹配、教学化“阶段规划”
  cube_view.gd           3D 渲染与交互：角块建模、转动动画队列、
                         射线拾取 + 拖动方向 → 转动层的推断
  cube_net.gd            2D 展开图（十字展开，实时配色，自动缩放）
  lessons.gd             教学课程文本与局面设置（口语化、面向中小学生）
  ui.gd                  全部 UI（代码构建）：明亮大字号主题、步骤进度、
                         “下一步”提示条、撒花庆祝
  feedback.gd            音效反馈（代码合成短音，不依赖外部音频素材）
  main.gd                场景搭建（环境 / 灯光 / 相机）、课程流程、教练引导、
                         计时统计与最好成绩存档（user://）
tests/                   无界面与渲染自测脚本（含 kids_ui 交互自测）
```

### 关键实现点

- **状态表示**：8 个角块，每个角块用 `code = 位置索引 * 3 + 朝向`（0..23）表示，
  与 24 种旋转一一对应。朝向采用标准约定（绕槽位外法线扭转 120° 的次数），
  因此“所有角块朝向之和 ≡ 0 (mod 3)”这一不变量成立。
- **转动表**：启动时预计算 `MOVE_TABLE[move][角块][code] -> code`，
  转动逻辑就是 8 次查表，既快又不会出现浮点误差。
- **动画**：把要转的 4 个角块临时挂到一个 `pivot` 上补间旋转，
  动画结束后按模型状态精确“对齐”回原位（`_sync()`），因此不会误差累积。
- **拖动转层**：射线拾取得到面法线 `n` 与拖动的屏幕方向，
  在世界坐标的 4 个切向里挑屏幕投影最接近的那个 `t`，
  于是旋转轴 `a = n × t`、层号 = 触碰角块在 `a` 上的符号 —— 手感和真实魔方一致。
- **白色一层求解**：BFS 预计算 4 个白色角块 (位置, 朝向) 共 136,080 个状态的
  精确最少步数，再沿距离梯度下降 → **最优解、亚毫秒级**。
  这张表在启动后分帧构建（每帧最多 7 ms），不会卡住主线程。
- **OLL / PLL**：所有标准公式都会**仿真验证**（4 种前置 AUF × 4 种后置 AUF），
  只有真正能把状态送到目标才使用，绝不会给出错误公式。
- **稳定的“走一步”**：提示时把整套已验证的引导序列缓存下来，逐步执行；
  只有当小朋友自己动手或重新分析时才作废，避免在 OLL / PLL 阶段来回摆动。
- **音效**：用 `AudioStreamWAV` 在运行时合成 16-bit PCM 短音，项目里没有任何音频文件。

## 五、配色与记号

西方标准配色：`U` 黄、`D` 白、`F` 绿、`B` 蓝、`R` 红、`L` 橙。

转动记号：`R` 右面顺时针 90°（从右面看），`R'` 逆时针，`R2` 转 180°。
`U / D / L / F / B` 同理。

内置公式：

```
OLL（顶层朝向）
  小鱼 Sune            R U R' U R U2 R'
  逆小鱼 Anti-Sune     R U2 R' U' R U' R'
  H 型                 R U R' U R U' R' U R U2 R'
  Π 型（Pi）           R U2 R2 U' R2 U' R2 U2 R
  T 型                 R U R' U' R' F R F'
  L 型                 F R' F' R U R U' R'

PLL（顶层归位）
  相邻两角互换         R U R' U' R' F R2 U' R' U' R U R' F'
  对角两角互换         F R U' R' U' R U R' F' R U R' U' R' F R F'
```
